# 需求表自動建案（Apps Script Webhook）

客戶在需求表按「送出」→ 自動把新案加進 Google 試算表 `01_案件總控`（狀態＝洽談中），
並存一份完整原始回覆到「需求表原始回覆」分頁、寄一封通知信。不用再手動加案子。

## 架構
```
需求表 HTML（送出）
   │  navigator.sendBeacon(WEBAPP_URL, 表單資料)   ← 前端已接好，不影響原本 email/導回感謝頁
   ▼
Apps Script Web App：doPost(e)
   ├─ 寫入 01_案件總控（去重、狀態＝洽談中）
   ├─ 存原始回覆到「需求表原始回覆」
   └─ 寄通知信給你
```

## 部署步驟（一次性，約 5 分鐘）
1. 把 `需求表自動建案.gs` 貼進你的 Apps Script 專案。
2. 右上 **部署 Deploy → 新增部署作業 → 類型：網頁應用程式**
   - 執行身分：**我**（你自己）
   - 具有存取權：**任何人**
3. 複製產生的 `.../exec` 網址。
4. 把網址貼進**每一支需求表 HTML** 最上方的：
   ```js
   var WEBAPP_URL='';   // ← 貼在這對引號裡
   ```
   已接好的檔案：`合雄鳳璽_需求表.html`、`長堤天昀A2-5F_需求表.html`、
   `禹合制所_室內裝修需求表.html`、`中和地球村_需求表.html`
5. 測試：填一份需求表送出 → 看 `01_案件總控` 是否多一列、信箱是否收到通知。

## 注意
- 之後每次改 `.gs`，要「管理部署作業 → 編輯 → 版本：新版本」才生效。
- 需求表 HTML 是公開頁，端點屬公開可 POST；已用「案名去重＋通知信」把關。
  若日後被灌垃圾，再加共用密鑰或改用 Google 表單。
- `WEBAPP_URL` 留空時，需求表完全照舊運作（只寄 email、導回感謝頁），不會壞。
