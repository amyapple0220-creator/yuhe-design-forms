# 需求表自動建案（Apps Script Webhook）

客戶在需求表按「送出」→ 自動把新案加進 Google 試算表 `01_案件總控`（狀態＝洽談中），
並存一份完整原始回覆到「需求表原始回覆」分頁、寄一封通知信。不用再手動加案子。

## 架構
```
需求表 HTML（送出）
   │  navigator.sendBeacon(WEBAPP_URL, 表單資料)   ← 前端已接好，不影響原本 email/導回感謝頁
   ▼
Apps Script Web App：doPost(e)
   ├─ 寫入 01_案件總控（去重、狀態＝洽談中）
   ├─ 存原始回覆到「需求表原始回覆」
   └─ 寄通知信給你
```

## 部署步驟（一次性，約 5 分鐘）
1. 把 `需求表自動建案.gs` 貼進你的 Apps Script 專案。
2. 右上 **部署 Deploy → 新增部署作業 → 類型：網頁應用程式**
   - 執行身分：**我**（你自己）
   - 具有存取權：**任何人**
3. 複製產生的 `.../exec` 網址。
4. 把網址貼進**每一支需求表 HTML** 最上方的：
   ```js
   var WEBAPP_URL='';   // ← 貼在這對引號裡
   ```
   已接好的檔案：`合雄鳳璽_需求表.html`、`長堤天昀A2-5F_需求表.html`、
   `禹合制所_室內裝修需求表.html`、`中和地球村_需求表.html`
5. 測試：填一份需求表送出 → 看 `01_案件總控` 是否多一列、信箱是否收到通知。

## 注意
- 之後每次改 `.gs`，要「管理部署作業 → 編輯 → 版本：新版本」才生效。
- 需求表 HTML 是公開頁，端點屬公開可 POST；已用「案名去重＋通知信」把關。
  若日後被灌垃圾，再加共用密鑰或改用 Google 表單。
- `WEBAPP_URL` 留空時，需求表完全照舊運作（只寄 email、導回感謝頁），不會壞。

# 請款單資料 API（`請款單API.gs`）

給 `禹合制所_請款單.html` 用的資料來源，順便把「條件成就」跟 Google 行事曆綁在一起。

```
Google 試算表（私有）
  20_合約 / 21_請款排程 / 22_請款單 / 23_公司資料
        │
        ▼  doGet(?id=文件編號&k=金鑰)
Apps Script Web App  ──JSON──▶  禹合制所_請款單.html（GitHub Pages，本身不含任何資料）
```

⚠️ **請另開一個 Apps Script 專案**放這一支。它的 `doGet` 會跟 `需求表自動建案.gs` 的
`doGet` 撞名，貼在同一個專案裡兩邊都會壞掉。

## 設定步驟
1. 新專案貼進 `請款單API.gs`。
2. 執行 `建立分頁範本()` → 建好四個分頁與表頭。
3. 執行 `產生金鑰()` → 記下金鑰（存在 Script Properties，**不要寫進 repo**）。
4. 到 `23_公司資料` 填公司抬頭、統一編號、金融機構、戶名、帳號。
5. 到 `20_合約` 填各案的合約總額與簽約日；
   執行 `寫入預設分期("案名")` 產生分期表，再**對照實際合約修正比例與條件**。
6. 部署為網頁應用程式（執行身分：我／存取權：任何人），複製 `/exec` 網址。
7. 打開 `禹合制所_請款單.html` → 按「🔗 連線設定」貼上網址與金鑰（只存在自己的瀏覽器）。

## 日常使用
- **開單**：`建立請款單("合雄凰璽 B1-7F", "工程 第三期, 工程 第四期", "＜付款人＞")`
  → 產生文件編號並在紀錄印出連結。
- **給業主的連結**：
  `.../禹合制所_請款單.html?api=<exec網址>&id=<文件編號>&k=<金鑰>`
- **收到款**：`登記收款("合雄凰璽 B1-7F", "工程", "第三期", "2026-10-20")`
- **自動偵測條件成就**：先跑 `檢查條件成就_預覽()` 看會動到哪幾列，
  確認後把 `檢查條件成就()` 加「時間驅動」觸發條件，每天早上跑一次；
  有新的條件成就會寄信提醒開單。

## 安全
- 沒設金鑰時 `doGet` 一律拒絕，不會出現「沒防護的公開端點」。
- 一定要帶 `id`，只回傳那一張單，沒有「列出全部案件」的入口。
- 成本、發包單價、毛利不在這四個分頁裡，請款單只呈現售價與收款狀態。
- 沒有網路或不想連線時，請款單頁面可用「📋 貼上資料」直接貼 JSON 出單。

# 其他批次工具

- `案名統一.gs`：把試算表裡的案名寫法統一（忠泰湛 B2-22F、鉅力高宇D-2F、合雄凰璽）。
- `行事曆重複事件檢查.gs`：找出標題相同、日期相同的重複事件。
- `C2F報價簽約日校正.gs`：把鉅力高宇C-2F 的工程報價＋簽約由 8/31 改為 9/1（10:30）。
  案件總覽與 Google 行事曆已於 2026/08/19 校正，這支是補試算表的四處舊寫法。

三支都是「先跑 preview 唯讀預覽 → 確認後再跑 apply」，動手前請先建立試算表副本。
