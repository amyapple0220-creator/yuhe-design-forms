## 怎麼把丈量數字填進去

打開 `合雄凰璽B1-7F_現況平面_產生器.py`，只改最上面「丈量數據區」那一段：

1. **`GRID_X` / `GRID_Y`** —— 各道牆的軸線位置（mm，從左下角外牆外緣起算，累加）
   目前是：
   - `GRID_X = [0, 1700, 5400, 6800, 10400, 13200]`
     前陽台 ｜ 女兒房1 ｜ 走道 ｜ 廚房 ｜ 後陽台
   - `GRID_Y = [0, 2600, 4400, 6300, 7400, 10400]`
     主浴.房3 ｜ 主臥 ｜ 客浴 ｜ 廚房.後陽台
2. **`T_EXT` / `T_INT` / `COL`** —— 外牆厚、隔間厚、柱寬
3. **`OPENINGS`** —— 門窗開口：`(種類, 牆向, 軸線, 起, 迄, 牆厚, 門樞側, 開啟方向)`
   - 種類：`"D"` 門、`"W"` 窗、`"O"` 無門開口
   - 牆向：`"H"` 水平牆（沿 X）、`"V"` 垂直牆（沿 Y）
   - 門樞側：`"s"` 在起點、`"e"` 在迄點；開啟方向 `+1` / `-1`
4. **`ROOMS`** —— 房間範圍與名稱
5. **`FIXTURES`** —— 現況固定設備（浴缸、馬桶、流理台…），供拆除範圍判斷

存檔後執行：

```bash
python3 合雄凰璽B1-7F_現況平面_產生器.py
```

會重新輸出三個檔，並在終端機印出**各室面積對帳表**：

- **軸線面積**（含牆）—— 對應權狀實坪的算法，拿來跟「室內約 40 坪」對帳
- **淨地坪**（扣半牆）—— 實際可用地坪，拿來排傢俱與算地板數量

兩者差距約 3 坪是正常的（牆體佔用）。若軸線合計與 40 坪差超過 1 坪，
代表 `GRID_X` / `GRID_Y` 有一段量錯或漏掉，回去對丈量草圖。

## 現場還要補量的項目

以下是這份底圖沒有、但施工圖與估價一定會用到的，**複勘時要補**：

- 樑位與樑深、天花板淨高（現況天花為木作包覆，拆除後才是真實高度）
- 管道間實際位置與尺寸、糞管落點
- 配電箱位置、迴路數、總電量
- 窗框外框尺寸（是否更換）
- 各房現況地坪高低差（需求表要求全室齊平）
- 大門尺寸（業主指定保留不換，須量準）
